# hxwl-08 葡萄酒盲品训练

只凭感官线索辨认酒款的盲品练习工具：录入酒款与答案，反复训练，系统按答题结果调度复习节奏。

## 技术栈

React + Vite + TypeScript + CSS，数据保存在浏览器 localStorage（无需后端）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 功能

### 题库管理

- 录入酒款名称（即答案）、产区、品种、年份，以及训练时展示的四项线索：香气、酸度、单宁、酒体
- 编辑 / 删除酒款；删除时自动清理相关统计与混淆记录
- 首次打开自带 3 款示例酒；支持重置进度（保留题库）与清空题库
- 每款酒显示练习次数与单品正确率

### 盲品训练

- 每轮只显示**香气、酸度、单宁、酒体**，作答前酒名、产区等答案信息完全隐藏
- 从酒款列表中点选作答，提交后揭示答案，标出正确与误选项
- 侧栏实时展示「易混淆关系」：把哪款酒误判成了哪款，以及发生次数
- 顶部与题库页展示总轮次和总正确率

### 出题调度规则

- **答错**：记录混淆关系，该酒至少间隔 **2** 题再出现
- **答对**：至少间隔 **5** 题再出现
- 满足间隔的酒款中，**优先选择最久未出现**的（从未出现的酒优先级最高）
- 题量不足、所有酒都不满足间隔时放宽间隔，仍按「最久未出现」优先
- 任何情况下**当前题都不会紧接重复**；仅一款酒时不允许继续出题

### 持久化

题库、出题队列、当前题、每款酒统计、混淆关系与总体正确率全部存入 localStorage，刷新或重开浏览器后继续练习。
