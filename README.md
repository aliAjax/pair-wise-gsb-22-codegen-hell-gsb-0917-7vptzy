# hxwl-08 葡萄酒盲品训练

依据香气、酸度、单宁、酒体辨认酒款的盲品练习工具。

## 技术栈

React 19 + Vite + TypeScript + 原生 CSS，数据保存在浏览器 localStorage，无需后端。

## 本地运行

```bash
npm install
npm run dev              # 开发：http://localhost:5108
npm run build            # 生产构建
npm run test:scheduler   # 调度/冷却/混淆规则测试
```

## 功能

### 题库录入
- 酒款名（必填，即盲品答案）、别名（任填一个也算对）、产区、品种、年份——这些作答前隐藏；
- 香气关键词、酸度、单宁、酒体——作为盲品题面始终展示；
- 内置 3 款示例酒；酒款可删除（同步清理其统计与混淆关系）。

### 训练流程
- 每轮只显示香气、酸度、单宁、酒体，文本作答后才揭晓酒款名/产区/品种/年份；
- 支持「跳过 / 不会」，跳过按答错处理但不计混淆关系；
- 答案匹配忽略大小写、空白和括号备注，支持别名。

### 出题调度（全局题号驱动）
- 答错或跳过：`cooldownUntil = N+3`，至少隔 2 题再出现；
- 答对：`cooldownUntil = N+6`，至少隔 5 题再出现；
- 冷却期内若无可用题（题量不足）则放宽冷却，从非当前题中选**最久未出现**的，从未出现过的优先；
- 当前题在任何情况下都不会紧接重复（题库仅剩 1 款时给出提示）。

### 混淆关系
- 答错的文本记录为「答成什么 → 正确酒款」的成对关系；
- 若答的是题库中另一款酒的名字/别名，会标注撞款；
- 同一混淆对重复出现自动累计次数，侧栏按频次展示。

### 持久化
- 题库、逐酒款统计（出现/正确/正确率）、混淆关系、总正确率、进行中的当前题与揭晓状态全部存入 localStorage；
- 刷新页面后进度保留，进行中的一轮可继续作答；
- 「重置进度」只清统计与混淆，保留题库。
